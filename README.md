# 在线工具 · 你的工具箱

参考 tool.lu 的绿色导航、分类列表和工具卡片布局制作的纯前端工具站。只保留 **工具** 与 **网址** 两个栏目，无注册、登录或后台服务。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://127.0.0.1:5173/。

```sh
npm test       # 核心算法与边界情况测试
npm run build # 生成 dist/ 静态网站
npm run preview
```

## 功能

- **95 个工具**，按开发、文本、图像、文档、音频、视频、设计、学术、查询、音乐、运维、其他分类。
- 代码格式化：JavaScript / TypeScript / CSS / HTML / SQL / JSON / XML / YAML。
- 文本与编码：Base64 / URL / Hex / AES / 摘要、正则测试、拼音、简繁转换、Markdown / AsciiDoc / Mermaid、文本差异、表格、字幕。
- 图片：二维码、条形码、格式转换、照片压缩、裁剪、水印、拼图、图标、切图、手写签名、白板、GIF 分帧 / 缩放 / 裁剪。
- 文档：PDF 合并 / 分割 / 选页排序 / 旋转 / 页码、图片转 PDF、批量文件重命名 ZIP。
- 音频：剪辑为 WAV、节拍器、吉他参考音和麦克风测频。
- 计算与参考：时间戳、日期、分数、数学表达式、单位、CIDR、坐标、生肖、纸张尺寸、元素表等。
- 网址导航：9 类、85 个直达链接；站内搜索、分类筛选、锚点导航。
- 收藏保存在浏览器 localStorage 中；手机与桌面布局自适应。

## 实现范围与说明

这是独立实现的本地工具箱，不是原站源码或全部功能的逐像素复制。工具名称沿用通用名称，图标、描述、目录数据与代码独立制作。根据要求，移除了 AI 文案、实时 IP / 汇率 / DNS / Whois 查询、服务端反编译等依赖外部服务的功能；未复制原站的数据库、登录系统、商标或备案信息。

处理逻辑与依赖库均打包在站点中，不通过 CDN 加载。首次运行需要下载 npm 依赖；构建后的处理功能无需服务端 API。网址导航、文档里用户主动使用的外部链接会打开对应第三方网站。

- PDF 不支持加密文件；页码使用默认拉丁字体。
- 图片格式受浏览器解码支持范围限制；静态图片工具处理 GIF 时仅处理首帧，动画请使用专用 GIF 工具。
- 图片压缩输出是否变小取决于原图和输出格式；透明 PNG 转 JPEG 使用白色背景。
- 音频解码受浏览器格式支持限制，导出格式为 WAV。
- GIF 工具有内存限制，特别大的动画会给出提示。
- Curl 转换仅支持界面中列出的常用参数；字幕转换为 SRT / VTT，不含翻译。
- 字帖拼音、元素信息、尺码等是本地工具或静态参考。生肖按公历年份对应农历年显示，春节之前请参考上一年。
- 吉他麦克风测频需要用户授权，只在本地处理音频；麦克风设备实测未纳入自动检查。

## 目录

- `src/catalog.js`：工具目录
- `src/main.js`、`src/style.css`：两栏目布局、路由、搜索与收藏
- `src/*-tools.js`：按类型拆分的工具界面和处理逻辑
- `src/core.js`、`src/coordinates.js`：独立算法
- `src/nav-data.js`：网址导航
- `tests/core.test.js`：算法、异常输入和注册表检查
